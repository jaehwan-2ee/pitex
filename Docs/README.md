## Writing guidance

Use short sentences and direct instructions.
Use the same technical term for the same function.
Keep one instruction in each numbered step.

These documents follow selected [ASD-STE100 guidance](https://www.asd-ste100.org/about_STE.html).
The [Issue 9 specification](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf) defines the complete standard.
This project does not claim certification or a measured compliance score.
